# Final handoff: RSNA knee MRI abnormality detection (2026)

Everything needed to understand and reproduce our best pipeline: the fold-average package and its all-data version, which
produced our two final submissions. Model checkpoints and raw competition data are not included.

## Result

- Task: 12 findings per knee MRI study (ACL, MCL, medial / lateral meniscus, medial / lateral / PF OA, effusion, synovitis,
  Baker's cyst, contusion, fracture). Metric = mean of the 12 per-class AUCs.
- Training data: 4,407 studies with radiology reports; 58 of them ("gold") also have the official image-based labels that the hidden
  test uses.
- Best fold-average package (v2, 57416173): public **0.964**.
- Finals (the same form retrained on all data):
  - **P1** (57517691, plain, 93 models): **0.965**;
  - **P3** (57520062, plain + pseudo-label twins, 117 models): **0.965**.

## Reproducing (outline)

1. Environment: `docs/02_TRAINING.md` 2.1 (PyTorch + CUDA, timm, pydicom, blosc2, opencv, scikit-learn, iterative-stratification).
2. Download the competition data -> `data/original_data/`. Run `code/data_prep/build_data.py`, build the slice cache
   (`python -m common.cache build` + `jpeg`), and train / run the localisers and the flip detector (`docs/02_TRAINING.md` 2.2).
3. Put `label_data/` files where the trainers expect them (`docs/02_TRAINING.md` 2.3). The text v1 labels are read by
   `common/labels.py` from `data/text_labels/v1.json`.
4. Train every recipe in `code/training/recipes/` on its folds (fold package) or on all data with 3+ seeds (finals) with the
   launchers (`docs/02_TRAINING.md` 2.4).
5. Assemble the package (`code/inference/packaging/`), run the gates, render the kernel, check it with a Kaggle commit, and submit
   early (`docs/04_INFERENCE_AND_KAGGLE.md`).

## Not included

- Checkpoints of any kind (`*.pt`); the final weights live in our private Kaggle datasets `knee-oct21-fa-*`.
- Raw competition data (DICOM, CSVs, radiology reports). The labelling bundles' `reports.csv` / `tiles.csv` / `studies.csv` are
  regenerated by their build scripts.
- Large regenerable intermediates: slice cache (~30 GB), `data/meta`, localiser predictions (`loc_pred*`, 60-113 MB each), crop
  bag caches.
- Anything from the external OAI dataset (tried, not used in any submission; its data use agreement keeps it off this repo).
- Public notebooks' label tables (`steven_v2`, `pilkwang_v2`, `lixin_sol56`) that `common/labels.external()` can read for
  comparison.

## Caveats

- Code is copied as it ran. Many scripts hold absolute paths (`/home/pavel/Programming/knee-abnormality-2026/...`) and expect the
  original layout:
  - `experiments/<version>/<name>/` with its own `data/`, `refs/`, `runs/`;
  - `data/` and `submissions/` at the repo root.

  Adjust the roots before running.
- The two trainer sets are deliberate copies (each experiment was self-contained). Use the trainer named in the recipe table for
  each recipe.
- `label_data/` holds derived labels of the competition training set (LLM reads of reports and images). Keep this repository
  private.
