### Phase 4, session 1: image + report labels, Baker's cyst only, batch p4_s1 (20 studies)

You are labelling knee MRI studies for a research dataset. Work in /home/pavel/Programming/knee-abnormality-2026. Other labelling chats run at the same time with their own lists; never touch their files.

Task: work through work/claude_labels_oct20/_batches/p4_s1.txt strictly in order. Each line is "INDEX bakers_cyst". For each index, label ONLY the Baker's cyst finding (bakers_cyst). The list says which finding to label, not whether it is present. Many listed studies have no cyst or only a small one, so judge each one exactly as you would in a full read.

Instructions: work/claude_labels_oct20/_prompts/prompt.txt (read-only: never modify that folder). Follow it exactly, with the changes below; where they conflict, these changes win. Before the first study, read prompt.txt (at least "The images", the Baker's cyst section, the certainty rules and the output format), definitions.md and schema_p4.json in full.

Change 1 - the panel: each file follows schema_p4.json and holds "panel": "p4", with no structures list. Its findings object holds exactly bakers_cyst, nothing else. Use every rule prompt.txt gives for Baker's cyst (grade, diameter_mm, neck_seen, ruptured, other_cysts; the status rules from grade).

Change 2 - every study HAS a radiology report (this replaces "There is no report: you label from the images only"):
- views.py copies it to report.txt next to the study's sheets. Read it, then label from the images AND the report together.
- The report was written by the radiologist who read every slice; you see a subset. Your labels are checked against expert image reads that apply the host definition in definitions.md ("a moderate or large fluid collection in the characteristic location behind the knee"), and report wording and size thresholds vary by site and radiologist. So the report is evidence, not the answer: decide from what you see first, then compare with the report.
- If the report states a cyst clearly and you cannot see it, keep it likely, unless the images clearly contradict it. If the report is silent or vague, decide from the images.
- In the note, name the native views you looked at (series + slice range, e.g. "s3 AX PD FS #4-12"), give the largest diameter you measured, then end with the source tag "images", "both" or "report".

Change 3 - sheets: open only 1_sag_fs, 3_ax_fs and 6_medial (this replaces "look at every sheet of the study"). sheets_viewed lists exactly the sheets you opened. validate.py requires the ones of these the study has.

Change 4 - looking, for EVERY study: before deciding, open at least one native full-resolution view with work/image_labeling/view.py show ... --box (an enlarged crop), written into your temp folder:
- an axial fluid-sensitive series through the popliteal fossa, behind the medial femoral condyle, between the medial gastrocnemius head and the semimembranosus tendon (look for the neck);
- a sagittal fluid-sensitive series through the posteromedial knee for the cranio-caudal extent.
Measure the largest diameter with the 10 mm bar. Tell apart the bursae, parameniscal cysts, ganglia and popliteal vessels that prompt.txt lists under "Does not count".
Keep the same care for the last study as for the first.

Change 5 - text reference first. Read work/claude_labels_oct20/_prompts_pilot/anchors.md. Run views.py for anchors 3297 and 3831 (both: Baker's absent per report) and look at their report.txt and the Change 3 sheets once. Never save labels for anchors.

Change 6 - output: work/claude_labels_oct20/p4_s1/ (create it): one <study_id>.json per index. No archive and no download link. Temporary files: only in work/claude_labels_oct20/_tmp_c56/. For each study (and each anchor) run, from the repo root:
