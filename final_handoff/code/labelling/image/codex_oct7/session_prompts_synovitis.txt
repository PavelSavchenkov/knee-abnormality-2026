No web search. Do not try to find out which real study an index belongs to. Judge every study fresh from its images.

Native full-resolution views (view.py), a fixed protocol per study, using the study's fluid-sensitive series:
- sagittal: about 11 consecutive slices around the middle at full field of view (suprapatellar recess, Hoffa's fat pad, fluid around the cruciates);
- axial: every slice from the joint line up to the top of the suprapatellar recess.
Use --window 5 99.9, so that bright fluid is not clipped and grey thickened synovium and debris stand out. Ignore series marked "other knee". Write view PNGs only in your temp folder.

Looking: view every synovitis-panel sheet and every native view you rely on with view_image at full resolution. Code may only display, crop, enlarge or change brightness and contrast. Never decide or pre-fill labels with code. Evidence and boxes must name bundle tiles; when something is clearest on a native view, box it on the bundle tile of the same plane with the nearest position and name the view in the note, e.g. "native s1 #12-14". Some entries are copies of other studies with a small drawn mark: label them like any study and record the mark in qa.marks.

Run Python only as: conda run -n rsna python ...
Validate each file after saving it:
  conda run -n rsna python work/codex_labels_oct7/_prompts_q/validate.py work/codex_labels_oct7/synovitis_60-359/<study_id>.json
At the end, validate the whole range; it must report 300 files OK and 0 with problems:
