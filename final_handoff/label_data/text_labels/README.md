# Text labels

`v0.json`, `v1.json` and `gold_text_labels.json` are built by `work/text_labeling/export_labels.py VERSION`; `v2.json` by
`work/text_labeling/v2v3/export_v2.py`; `v3.json` by `work/text_labeling/v2v3/export_v3.py`.

- `v0.json`: LLM labels of the train reports, keyed by study_id. One object per study in the format of `work/text_labeling/bundle_v0/schema.json` (status, missing, quote and attributes for 12 findings, plus study fields), produced with `work/text_labeling/bundle_v0/prompt.txt`. All 4,407 studies.
- `v1.json`: same as v0 plus a `probability` per finding (fixed values per status, chosen by wording rules), produced with `work/text_labeling/bundle_v1/` (second runs of 4 ranges, kept for repeatability checks, are in `work/text_labeling/returned_v1_repeat/`). All 4,407 studies.
- `gold_text_labels.json`: my hand labels of 208 reports (`set`: gold58 = the official gold studies, random150 = a random sample stratified by language), keyed by study_id. Per finding: `status` in the bundle vocabulary, my original `reason` code, `quote`, `note`. These follow the earlier rubric (`experiments/v0/oct7_baseline/analyses/text_gold/RUBRIC.md`): no `general_normal`, and ganglion cysts and cartilage-only fractures are not mapped to `excluded`.
- `v2.json`: every statement of each report as typed facts, with no label decisions. Keyed by study_id; all 4,407 studies.
  - Source: ChatGPT project sessions (2026-10-09), one per range of 50 studies (89 ranges), following `text_labeling_bundle_v2/prompt.txt`; returned archives in `work/text_labeling/returned_v2/`. Output format and allowed values: `text_labeling_bundle_v2/schema.json`. Index order is the same as v1. The exporter writes the labellers' objects unchanged.
  - `report`: `side`, `style` (`structured`, `narrative`, `impression_only`, `empty`), `compares_prior`. `context` (from the clinical history only): `trauma` (`recent`, `remote`, `none`, `not_stated`), `prior_surgery`, `age_years`, `quote`.
  - `facts`: a list, in report order. Each fact has `structure` (ligaments, menisci, cartilage / bone sites, joint, synovium, popliteal fossa, other bursae, Hoffa's fat pad, extensor tendons, soft tissue, global), `finding` (e.g. `tear`, `partial_tear`, `effusion`, `marrow_edema`, `cartilage_defect`, `normal`), `assertion` (`present`, `present_indirect`, `probable`, `possible`, `questionable`, `absent`, `absent_qualified`), `scope` (`specific`, or `group` when one statement named several structures), `section` (`findings`, `impression`, `both`), `quote`, and only the attributes the report states: `part`, `tear_type`, `grade` + `grade_system`, `percent`, `depth`, `size_mm`, `extent`, `severity_word`, `acuity`, `cause`, `displaced`, `graft`, `change`. Normal statements and denials are facts too (`normal` + `present`; `tear` + `absent`).
  - The 12 labels are not in the file: they have to be derived by code from the facts and the official definitions. Things such code must handle:
    - Each alternative of "X or Y" is recorded as `possible`, even when both alternatives meet the definition: "complete or near-complete ACL tear" gives `complete_tear` + `partial_tear` (high_grade), both `possible`.
    - Post-traumatic marrow edema is often recorded as `marrow_edema` with `cause` `trauma` ("pivot shift", "post-traumatic edema") rather than as `contusion`; both describe a contusion.
    - When the impression differs from the findings, both are kept as separate facts (`section`).
    - `style` `empty` with no facts also marks reports whose content is all outside the vocabulary (4 reports about iliotibial band friction, a shoulder report at index 300).
  - The clinical history rarely states trauma (174 studies `recent`) or age (5 studies).
  - Checks: all files pass `validate.py`; facts per study median 18 (session means 15.5-20.6, no drop within batches). Second runs of ranges 1050-1099 and 2350-2399 (`work/text_labeling/returned_v2/*_repeat1/`, not exported) give the same (structure, finding, assertion) sets with mean Jaccard 0.95 and 0.93 and the same meniscal and ACL tears.
- `v3.json`: for each of the 12 findings, a forecast from the report text of the label the annotating radiologists gave from the images. Keyed by study_id, all 4,407 studies.
  - Source: 5 Claude Code sessions (Claude Opus 5.5, 2026-10-08) following `text_labeling_bundle_v3/prompt.md`; session K labelled the studies with index % 5 == K (index = row of `text_labeling_bundle_v3/reports.csv`, the same order as v1). Output format: `text_labeling_bundle_v3/schema.json`. The exporter writes the labellers' objects unchanged.
  - `report`: `side`; `coverage` (`systematic`, `partial`, `minimal`, `empty`); `setting` (`acute_injury`, `degenerative`, `mixed`, `postoperative`, `unclear`).
  - Per finding:
    - `evidence`: what the report says about the finding, judged against the official definition: `qualifying`, `likely_qualifying` (deciding size / grade / acuity missing, or probable), `uncertain`, `subthreshold` (present but below the definition), `excluded` (assigned elsewhere by the definition), `silent` (not mentioned), `covered_normal` (only a group or whole-knee normal statement), `negative` (denied, or this structure called normal).
    - `p`: integer percent, the forecast that the annotators labelled the finding positive. It always lies in the range of its class: qualifying 80-98, likely_qualifying 50-85, uncertain 25-65, subthreshold 8-45, excluded 3-25, silent 2-45, covered_normal 2-20, negative 1-10.
    - `clues`: codes of the context that moved p (clinical setting, related findings, how thorough the report is); `quote`: the deciding words, "" for silent.
  - Difference from v1: v1 judges each finding only from the statements about it and gives no value to findings the report does not mention. v3 also uses the clinical history, related findings and the report's thoroughness, so silent findings get a value from context (2-45). v3 findings are therefore not independent of each other: for example, silent synovitis is ranked mainly by the reported effusion.
  - Silent values start from a fixed table in the prompt (per finding and setting) and were meant to move at most about 10 points. All labellers moved 11-16% of silent values further down (mostly where the report denies an effusion), and these values were kept. The mean silent value per part is 9.7-10.5.
  - Correction of part 3 (index % 5 == 3), 2026-10-09: its labeller had raised 253 silent values by script to "table value minus 10" and kept later values at that floor. The 253 values were restored to the labeller's own values from its session log; 115 later values at the floor were re-judged against the reports and the other parts' values in the same situation (94 lowered, 21 kept); the effusion and contusion values of study 1688 were set to the median of 4 identical reports in other parts. Every change, with its reason: `work/text_labeling/v2v3/part3_fix_changes.csv`.
  - The start table and the associations listed in the prompt were written by someone who had seen summary statistics of the gold-58 labels, so gold-58 is not an independent test of v3.
  - The labellers' notes on 50 hard reports (sections that contradict each other, bilateral reports, a shoulder report at index 300) are in `work/text_labeling/v2v3/v3_unsure.txt`.
